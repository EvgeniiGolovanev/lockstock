# LockStock Operational Maps

LockStock Operational Maps translate workflow documentation into the same visual system as the authenticated app. The diagrams use warm grid paper, square black borders, hard offset shadows, and the orange accent already used by the product. They should feel like product-native implementation maps rather than generic process drawings.

The palette is intentionally narrow: black for structure and navigation, orange for primary actions, cream for attention states, green for completed or valid outcomes, and red for stop states. This mirrors LockStock tables, status pills, KPI cards, and action buttons so the workflow pictures look like an extension of the live application.

Composition favors dense operational clarity. Each major workflow is framed like a product card with a black title bar, then broken into square modules with direct arrows and minimal copy. Loops appear only where the workflow permits repeated action, such as partial purchase order receiving.

Typography follows the app’s assertive style: heavy labels, compact uppercase tags, and short explanatory lines. The result is practical enough for implementation planning and QA, while still visually aligned with the LockStock interface.
